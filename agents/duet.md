# Duet

Duet is the Duet CLI agent harness. We believe it is `dzhng/duet-agent`, but this is not confirmed.

## How it loads skills

Duet reads `<cwd>/.duet/skills`, `<cwd>/.agents/skills`, `~/.duet/skills`, and `~/.agents/skills`. It advertises metadata only, and the body loads on demand. Skills installed to `~/.agents/skills` by `scripts/install-skills.sh` serve it.

## Use

1. Read the generated table in this file for the current skill set.
2. Run `./scripts/install-skills.sh` for a dry run, then `./scripts/install-skills.sh --apply <skill-dir-name>` for each listed skill.
3. Run the task. Duet loads matching skills on demand.

## Rules

- The generated table holds at most 12 skills.
- Load on demand only. Never install the whole library.
- Use Superpowers-style coding skills only in coding agents.
