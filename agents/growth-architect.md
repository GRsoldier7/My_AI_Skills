# Growth Architect

Growth Architect is a Grok Bot specialist that owns offer, pricing and packaging, positioning, lead magnets, retention loops, and health-claims guardrails, primarily for TempleProtocol.ai.

This index did not exist before 2026-11-26. The generated table is the starter set Aaron approved that day: `offer-and-pricing-review`, `competitor-value-prop-scan`, `lead-magnet-spec`, `retention-loop-design`, and `claims-guardrail-check`. All five are portable library skills. `case-study-draft` belongs with E7 Client Growth; this repository has no `e7-client-growth` agent index, so that skill is not listed here.

## How it loads skills

Skills load on demand from `/home/box/agent-data/workflows`. Fenced skills live in `agents/grok-bot/skills/` and are not portable. They depend on the box roster and lanes, agent-os scripts, `history.jsonl` ledgers, and approvals files.

Restore a fenced skill by copying `agents/grok-bot/skills/<name>/` into `/home/box/agent-data/workflows/<name>/`. Do this only with Aaron's yes for that skill. Foundry applies the change and runs CI.

## Use

1. Read the generated table in this file for the current skill set.
2. To restore a fenced skill, copy its folder to the box path above, with Aaron's approval.
3. Run the task. Growth Architect loads matching skills on demand.

## Rules

- The generated table holds at most 12 skills.
- Fenced skills never appear in `platform-configs/skill-sets/global.txt` or in any non-Grok index.
- Load on demand only. Never install the whole library.
