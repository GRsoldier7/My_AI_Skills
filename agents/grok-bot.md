# Grok Bot

Grok Bot is a team of specialist bots on one Linux box. Skills live in `/home/box/agent-data/workflows` and load on demand by name and description.

## How it loads skills

Skills load on demand from `/home/box/agent-data/workflows`. The 9 fenced skills in `agents/grok-bot/skills/` are not portable. They depend on the box roster and lanes, agent-os scripts such as `scripts/llm.sh`, `history.jsonl` ledgers, and approvals files.

Restore a fenced skill by copying `agents/grok-bot/skills/<name>/` into `/home/box/agent-data/workflows/<name>/`. Do this only with Aaron's yes for that skill. Foundry applies the change and runs CI.

## Use

1. Read the generated table in this file for the current skill set.
2. To restore a fenced skill, copy its folder to the box path above, with Aaron's approval.
3. Run the task. Grok Bot loads matching skills on demand.

## Rules

- The generated table holds at most 12 skills.
- Fenced skills never appear in `platform-configs/skill-sets/global.txt` or in any non-Grok index.
- Load on demand only. Never install the whole library.
