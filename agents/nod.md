# Nod

Nod is the n8n Labs personal agent (Apache-2.0, research preview). It ships 27 built-in task guides in `src/runtime/skills`.

## How it loads skills

Add extra guides to a self-hosted checkout at `src/runtime/skills/<name>/SKILL.md`. Restart Nod after adding them. Nod can also save learned skills through its skills tool. Copy only the skills listed in this file.

## Use

1. Read the generated table in this file for the current skill set.
2. Copy the listed skill folders into `src/runtime/skills/` of your self-hosted Nod checkout.
3. Restart Nod. It loads matching skills on demand.

## Rules

- The generated table holds at most 12 skills.
- Load on demand only. Never install the whole library.
- A restart is required after adding skills.
