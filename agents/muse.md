# Muse

Muse is Aaron's self-hosted personal chief-of-staff agent. It covers the homelab, an Obsidian vault, and Claude and OpenAI worker models.

## How it loads skills

The runtime loader is not confirmed. Point Muse at `agents/muse.md`, or symlink the listed folders into the skills directory its runtime reads. Skills follow the Agent Skills standard: the name and description stay in the prompt, and the body loads on demand.

## Use

1. Read the generated table in this file for the current skill set.
2. Point Muse at `agents/muse.md`, or symlink the listed skill folders into its runtime skills directory.
3. Run the task. Muse loads matching skills on demand.

## Rules

- The generated table holds at most 12 skills.
- Load on demand only. Never install the whole library.
- Use Superpowers-style coding skills only in coding agents.
