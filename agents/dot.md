# Dot

Dot is the OpenAI ChatGPT dot, an always-on work agent. It uses local skills only when a computer is connected. In cloud-only mode it has connected apps, not skills.

## How it loads skills

With a connected computer, Codex reads `~/.agents/skills`. Install the listed skills there with `scripts/install-skills.sh` (Codex target). Skills load on demand by name and description.

## Use

1. Read the generated table in this file for the current skill set.
2. Run `./scripts/install-skills.sh` for a dry run, then `./scripts/install-skills.sh --apply <skill-dir-name>` for each listed skill, using the Codex target.
3. Run the task. Dot loads matching skills on demand.

## Rules

- The generated table holds at most 12 skills.
- Load on demand only. Never install the whole library.
- Skills work only when a computer is connected.
- Use Superpowers-style coding skills only in coding agents.
