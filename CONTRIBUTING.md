# Contributing

All changes reach `main` through a pull request. Do not push directly or force-push. Run the checks below before you open one.

## Layout

- `skills/<domain>/<skill>/SKILL.md`: portable skills.
- `agents/<agent>.md`: one entry-point index per agent. The skill table is generated between agent-index markers.
- `agents/grok-bot/skills/`: 9 fenced Grok Bot-only skills. Never portable.
- `registry/curation.json`: hand-maintained curation (domains, core sets, caps, agent lists, review list, third-party provenance, box mirrors).
- `registry/skills.json`: generated by `python3 scripts/generate-skill-registry.py --registry`. Do not edit it by hand.
- `registry/moved.json`: old path to new path for the 32 moved paths.

## Statuses

| Status | Meaning |
| --- | --- |
| `core` | Default pick for the domain. |
| `optional` | Load by name when the task needs it. |
| `review` | Flagged for overlap, unsupported dependencies, unclear use or thin content. Read the reason before trialing. |
| `deprecated` | Kept for one window, then removed only with Aaron's yes. |

## Caps

| Cap | Limit |
| --- | --- |
| Core skills per domain | The domain's `core_cap` (max 12) |
| Skills in an agent index | 12 |
| Global install set | 5 (`platform-configs/skill-sets/global.txt`) |
| Library soft cap | 240 (current totals in the generated registry) |
| Intake adds per scout run | 3 |

## Add your own skill

1. Create `skills/<domain>/<skill>/SKILL.md`.
2. Update `registry/curation.json` (domain, core set, agent lists).
3. Regenerate the registry and run the checks.
4. Open a pull request.

Adding a core skill above a cap requires demoting or retiring one first.

## Add a third-party skill

A candidate must meet all of these:

1. License is MIT, Apache-2.0, BSD, or CC-BY, and the license file is present.
2. Vendored byte-identical at a pinned 40-character commit.
3. Recorded in `registry/curation.json` under `third_party` and in `scripts/lint-config.json` under `vendored_paths`.
4. Any scripts pass a static security review.
5. It fills a gap no existing skill covers.
6. No more than 3 intake adds per scout run.

## Retirement

- Propose deprecation for a skill that has had status `review` for 60 days.
- Propose deprecation for a skill with no agent index listing and no use evidence for 180 days.
- A deprecated skill stays for one compat window (90 days).
- Delete it only with Aaron's explicit yes in a pull request.
- Nothing is deleted automatically.

## Compatibility symlinks

Compatibility symlinks stay at least 90 days (until 2027-02-16). Remove them only in a separate pull request that Aaron approves, after each device re-runs its installer. See `MOVED.md`.

## Checks

After curation changes regenerate from the entire checkout. Then run the portable release check. Python 3.10 or newer and Git are required.

```sh
python scripts/generate-skill-registry.py --registry
python scripts/check-library.py
```

On Linux, also run `bash scripts/test-install-skills.sh` and `bash scripts/validate-skills.sh --category faith`. Run `python scripts/lint-skills.py --json` for the raw audit. The release check prints its findings count and fails on unexpected failures. Two references to an optional external capture skill in the pinned, review-status `git-commit-push-pr` are documented in the [verification report](docs/20261121%20-%20My%20AI%20Skills%20-%20Verification%20Report.md). Verify the dependency or select the simpler commit skill when trialing that package.

The master selector reads the same registry and returns one owner. The generator's legacy `--inject` option refreshes the canonical registry and agent tables. `--dry-run` checks their freshness. For a curated profile, edit its existing text set and review its allowed hosts, referenced resources, and an example task. Outside the repository, keep one private context per project or client.

`--check` fails on:

- a stale registry or agent index
- a core set over its domain cap
- an agent index over 12
- a fenced skill in a non-Grok index
- a name used twice
- a broken compatibility link
- a third-party skill without a license file or a pinned 40-character commit
- a global install set over 5

`--check` warns on a library over the 240 soft cap and on likely overlaps (description word overlap).

`lint-skills.py` and `validate-skills.sh` skip compatibility symlinks and include `agents/grok-bot/skills`. Use `--category grok-bot` to target that folder.
