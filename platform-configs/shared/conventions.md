## Work and verification

Follow the project's instructions, naming conventions and existing tests. Choose one workflow owner. Use project-router for lifecycle decisions when available, and use a specialist directly for a bounded task. Check the result against the request and report which checks actually ran.

For dated plans and reports use `YYYYMMDD - {Tool/Project} - {Short Concise Description}` and the project owner's local date. Match a Markdown report's H1 to its filename stem. Machine entrypoints keep the filenames their tools require.
