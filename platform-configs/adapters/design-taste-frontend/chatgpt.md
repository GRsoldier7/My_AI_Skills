# Taste — ChatGPT guidance

Reduced-capability adaptation of Taste 2.1.5, MIT, revision `12af471f627f866411b4bd785b19646d3672784c`. This host does not gain Node, Chrome/Edge, image-search scripts or automatic inspection from a skill. Do not fabricate a dealt direction, browser score or screenshot review.

1. Classify the deliverable: a page is read/scrolled; an app screen is worked in. Preserve the user's stack, brand and true content when refining an existing artifact.
2. Inventory the subject: audience, real capabilities, distinctive facts, constraints, owned visual material and the intended action. Derive the visual concept from those facts instead of a category template.
3. Write the argument before the layout. Each section needs a claim and evidence; remove invented testimonials, fake counts and decorative sections without purpose.
4. Choose one coherent direction manually. Decide type hierarchy, palette roles, content density, composition and image treatment. Record this as an authored choice, not output from the unavailable upstream random-deal script.
5. Build the result with the host's available artifact capabilities. For app screens, prioritize task hierarchy, consistent panels, aligned values, honest charts, and loading/empty/error/zero states. For pages, use complete content and relevant imagery rather than empty space or repetitive cards.
6. Use owned or appropriately licensed images with credits. Do not claim that an image search or license verification ran without evidence. Any remote asset or service depends on this host's permission and delivery restrictions.
7. Inspect available renderings at desktop and narrow widths. Check content overflow, hierarchy, mobile navigation, focus, semantic controls, contrast, reduced motion and truthful data. If no browser is available, source review remains useful but runtime/interaction checks remain unverified.

Deliver the artifact or concrete design/code supported by this host, explain the main choice briefly, and list only material unverified checks. Avoid requesting extra tools as a default step.

[Complete pinned skill and its references](https://github.com/Leonxlnx/taste-skill/tree/12af471f627f866411b4bd785b19646d3672784c/skills/taste-skill). The full runtime package separately needs approved Node 22+ and an installed compatible browser; no MCP is required.
