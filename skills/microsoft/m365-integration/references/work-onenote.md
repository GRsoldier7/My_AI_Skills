# OneNote meeting record and runbook draft

Use for a durable, searchable meeting record, troubleshooting note or procedure. Return a paste-ready page and its proposed notebook/section. Use a supplied authorized excerpt for OneNote-specific content. Existing Outlook and SharePoint readers do not establish OneNote access. No notebook edits or sharing take place.

**Frame the note.** Identify the audience, event or incident, local date/time zone, and the decisions or evidence a later reader needs. Use the existing notebook/section if specified. Cite exact source links or source IDs with date/version and the specific heading, paragraph or event occurrence. Mark partial evidence.

## Page template

**Page title** — YYYY-MM-DD · [system or meeting] · [result]  
**Proposed location** — [Notebook] / [Section]  
**Purpose and context** — [One sentence identifying the issue and scope]  
**Observed facts** — [Time, observation, source reference]  
**Decisions** — [Who decided what, when and on what evidence]  
**Follow-up** — [Action, confirmed owner, due date/time zone, status]  
**Open questions** — [Unresolved or conflicting evidence and verification owner]  
**References / reviewed** — [Exact source locations, versions if available, as-of time]

For a runbook add prerequisites, numbered steps, expected result at each critical step, stop condition, recovery/rollback, and review owner/date. Flag an untested procedure as a draft. Link to a maintained action tracker if one already owns the tasks.

**Synthetic example.** An agenda lists “approve the pilot.” Notes say “defer until counts reconcile.” Record the deferral as the outcome, cite the notes and list reconciliation as an action with an unknown owner if none is stated. An agenda alone establishes the planned discussion. It does not establish attendance or approval.

**Handoff.** Return only the minimum facts needed by the notebook audience. For a revision, retain the existing page title or identifier, list changed sections, and distinguish new evidence from previous notes. A human owner verifies the intended storage and readership before pasting.
