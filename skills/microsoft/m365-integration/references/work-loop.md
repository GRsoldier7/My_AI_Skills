# Loop decision and action tracker

Use for an evolving plan where several contributors need the same decision and action list. Deliver a paste-ready page in chat for a human owner. A SharePoint search result does not establish access to a Loop workspace or permission to create pages, share components or assign tasks.

**Inputs.** Ask for the decision or outcome, audience, tracking horizon and source excerpts only when missing information changes the page. Use existing permitted reading only when specifically requested. Retain exact evidence references and use role labels when names are unnecessary.

## Paste-ready page

**Title** — [Initiative] · working decisions and actions  
**Outcome** — [Measurable result and target date]  
**Steward / next review** — [Role] / [date and time zone]  
**Sources** — [Evidence ID, exact supplied link or item ID, version/date and heading]

| Kind / ID | Decision, action or question | Status | Accountable role | Due / next review | Evidence |
|---|---|---|---|---|---|
| Decision D1 | Use the approved intake definition for the pilot | Confirmed | Process owner | Review on 2026-12-07 | S1 v2, “Scope” |
| Action A1 | Reconcile three unmatched test rows | Requested | Unassigned | Unspecified | E1, paragraph 2 |
| Question Q1 | Who approves a definition change? | Open | Unassigned | Next review | S1 omits approver |

These rows are synthetic. Replace them with sourced content. On updates, preserve stable IDs, record what changed and its evidence, close superseded rows with a pointer, and collapse exact duplicates. If two sources name different owners, show both claims and leave assignment open. Distinguish a suggested due date from a commitment.

**Handoff.** Identify the existing page/component to reuse, the intended audience and the person responsible for confirming access. Link to one maintained tracker when possible. A restricted source stays restricted. For wider readership use an approved summary or omit the detail. Return the page and a short list of unresolved fields to the owner for placement.

**Acceptance.** Repeating A1 in a second note adds evidence to A1. A request that someone *could* handle it leaves its accountable role unassigned. An underlying source edit should prompt a new review of the affected row.
