# Provenance

Owner-authored bounded adaptation inspired by Karpathy Autoresearch:
https://github.com/karpathy/autoresearch/tree/228791fb499afffb54b46200aca536f79142f117

The upstream README declares MIT, without a standalone LICENSE in this revision.
No upstream training runtime, datasets, notebook, or agent program is copied.
This adaptation adds finite budgets, immutable scoring, isolated candidates,
preserved failures, cancellation reconciliation and separate promotion review.
It does not install a controller, launch a training job, or disable permissions.
