# Sources and Permissions

## Evidence

Start with an authorized Bible text. Use translations to expose questions, lexicons/grammars for language, original writings/reputable academic work for history, and primary confessions for a tradition's doctrine. Commentaries inform interpretation; they do not outrank Scripture. Distinguish quality from agreement.

Use available trusted retrieval before installing a platform. Confirm translation availability. Without authorized retrieval, use supplied text or reference-plus-paraphrase. Never silently label a substituted translation ESV.

Optional future tools, not installed dependencies:

- [TheologAI](https://github.com/TJ-Frederick/TheologAI): research MCP with configured ESV API access; sources span traditions. Test actual tools, rights, and outputs first.
- [Bible CLI](https://github.com/Divine-Creative-Ministries/bible-cli): offline lookup/analysis candidate; code and corpora have separate licenses, and ESV is not automatically included. Computed patterns still need interpretation.
- [YouVersion skills](https://github.com/youversion/platform-skills): engineering guidance for an authorized integration; verify translations against actual app entitlement, never invented IDs.

No Bible corpus, commentary database, credential, or external executable is bundled here.

## Quoting and publishing

Consult [current Crossway permissions](https://www.crossway.org/permissions/) for the intended ESV use and [ESV API terms](https://api.esv.org/) for that service. Checked 2026-10-29. Conditions differ by medium and include exclusions; a remembered verse limit alone does not clear publication. Commentary/reference works, public licensing, artwork, and commercial uses need particular care. Do not relicense Bible text under software terms.

Prefer references and original paraphrases when exact wording is unnecessary. Identify translation, verify wording, and preserve applicable attribution. Distinguish code license, data license, quotation permission, and API entitlement. Never redistribute a whole translation or paid notes merely because a tool can retrieve them.

If intended-use permission is unresolved, continue with references/paraphrases and flag the exact remaining question. Do not claim permission or contact rights holders without authorization.
