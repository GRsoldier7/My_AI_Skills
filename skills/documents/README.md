# Document skills — upstream references

DOCX, PDF, PPTX and XLSX apply across every domain. The requested Anthropic
packages use a restrictive source-available license, unlike the six Apache-2.0
packages imported alongside them. Their license restricts copying, retention
outside Anthropic Services and redistribution. Their implementation files are
therefore not copied into this public repository or Master_Skills.

| Format | Reference |
|---|---|

| PDF | [Source and license](pdf/README.md) |
| PPTX | [Source and license](pptx/README.md) |
| XLSX | [Source and license](xlsx/README.md) |

Use a provider-supplied document tool in an authorized host, or obtain terms that
permit a separate installation. These folders are references, not installed
SKILL.md packages, and are intentionally absent from executable profile lists.
