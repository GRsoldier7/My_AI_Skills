# Connector terms in this library

A tool name in a skill identifies a capability to check in the receiving workspace. It grants no access by itself. For the work BI pack, use only material the user supplied in the approved chat. A manual review can use a short synthetic table, a measure definition, expected totals and an optional screenshot that the user is permitted to share.

| When a skill requests… | Manual work BI input |
| --- | --- |
| A data warehouse, database or SQL runner | Query text and a small approved result or synthetic fixture. Label results the user supplied and calculations performed on the fixture. |
| A spreadsheet, notebook or dashboard | The relevant formulas, definitions, chart and filter context. Record what can be checked with those inputs. |
| A document store, chat connector or publishing target | The relevant approved excerpt. Return a review draft in the current conversation. |

Keep client and employer materials inside their approved workspace. Leave unavailable checks open and identify the smallest additional input they need. This document is repository-specific guidance for portable copies of externally sourced instructions.
