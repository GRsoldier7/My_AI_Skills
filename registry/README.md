# Registry

The registry holds the curation rules, the generated skill list, and the move map. It has three files.

## Files

- `registry/curation.json`: hand-maintained curation (domains, core sets, caps, agent lists, review list, third-party provenance, box mirrors).
- `registry/skills.json`: generated by `python3 scripts/generate-skill-registry.py --registry`. It carries one entry per skill and the library totals. Do not edit it by hand.
- `registry/moved.json`: old path to new path for the 32 moved paths (31 skills and the old folder README).

## Fields in `skills.json`

Each entry has `name`, `path`, `domain`, `portable`, `status`, `platforms`, `origin`, `license`, `version`, a one-line summary, and the upstream commit when vendored.

- `status`: `core`, `optional`, `review`, or `deprecated`.
- `platforms`: the agents whose index lists the skill.
- `origin`: `vendored`, `box-mirror`, or `library`.

## Commands

```bash
python3 scripts/generate-skill-registry.py --registry
python3 scripts/generate-skill-registry.py --check
```

The first command regenerates `skills.json` and the agent index tables. The second fails on a stale registry or index, a cap violation, a fenced skill in a non-Grok index, a duplicate name, a broken compatibility link, or a third-party skill without a license file or pinned commit. See `CONTRIBUTING.md` for the full list and the caps.
